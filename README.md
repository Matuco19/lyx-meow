# lyx-meow

Personal TUI runner for [slynx](https://github.com/Slynx-Language/slynx). Pounce on `.syx` files, knead the IR, nap when done. `(=^･ω･^=)`

## Install

```bash
cargo build
```

## Use

```bash
# one-shot pounce (default, no TUI)
cargo run -- examples/hello.syx

# interactive ratatui TUI
cargo run -- examples/hello.syx --tui

# interactive ratatui TUI, short flag
cargo run -- run examples/hello.syx -t

# tokens only (sniffing)
cargo run -- tokens examples/hello.syx

# custom std path
cargo run -- run examples/hello.syx --std=../slynx-fork/lib/std

# register mlyx shortcut on Windows (then use `mlyx` anywhere)
cargo run -- --register

# unregister the mlyx shortcut
cargo run -- --unregister

# fuzz the slynx pipeline (lex → load → hir → ir), bug cards in fuzz-out/cards
cargo run -- fuzz --init
cargo run -- fuzz --cases=200

# fuzz slynx's own rust sources as lexer-torture seeds (auto-finds ../slynx-fork)
cargo run -- fuzz --rust --cases=500
```

Fuzzing hunts panics and hangs across the whole slynx pipeline and files a
detailed card per unique hairball (`fuzz-out/cards/FUZZ-0001.md` + `.syx`
reproducer, plus `fuzz-out/summary.md`). Everything is tuned through
`lyx-fuzz.toml` (`run`, `stages`, `gen`, `mutate`, `corpus`, `report`
sections); CLI flags (`--config`, `--cases`, `--seed`, `--out`, `--rust`) win
over file values. Same seed replays the same hunt. Panics whose message holds
a `run.ignore_panic_contains` entry (default `"not implemented"`) are counted
as known todos, never filed.

Keys: `r` pounce (run) · `i` knead IR on/off · `t` sniff tokens · `o` new sunbeam (type a path) · `↑↓/jk` scroll · `q` nap (quit).

## Layout

- `src/cli.rs` — arg parsing, no deps
- `src/fuzz.rs` — staged fuzz hunt, oracles, bug cards, minimizer
- `src/fuzz_config.rs` — TOML config schema (`lyx-fuzz.toml`)
- `src/fuzz_gen.rs` — seeded grammar generator + mutator + edge pool
- `src/register.rs` — `mlyx` shortcut register/unregister (Windows shim + PATH)
- `src/runner.rs` — compile wrapper + timing
- `src/theme.rs` — green styles + tiny pixel accent
- `src/tui.rs` — ratatui event loop + panes
- `src/app.rs` — small state machine
